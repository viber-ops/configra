# Management workspace previews

These screenshots use synthetic, value-free test fixtures. The workspace includes
resource navigation, keyboard search, bounded field browsing, credential issuance,
and explicit sensitive-value reveal/conceal controls.

- [Light workspace](vault-light.png)
- [Dark workspace](vault-dark.png)
- [Mobile workspace](vault-mobile.png)
- [Certificate authorities](authorities.png)

The visual direction uses restrained typography, a quiet
blue navigation column, compact item identities, and a focused detail pane inspired
by desktop credential managers. The [design direction](../ui-design-direction.md)
records the palette and layout choices.
