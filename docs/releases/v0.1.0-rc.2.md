# Configra v0.1.0-rc.2

This preview replaces the withdrawn server rc.1. The repository starts from one
clean source snapshot without the old screenshot history. Public screenshots
remain on the [website](https://viber-ops.github.io/configra/); the Go SDK keeps
its existing release tags and history.

## Included

- YAML/JSON configuration, shared Vault values and per-environment versions.
- A Chinese/English management UI, with light and dark themes.
- Managed client CAs, encrypted signing-key storage, one-time private exports,
  client certificate issuance and revocation.
- Go SDK reads and both Kubernetes integrations: CSI-mounted files and native
  Secret/ConfigMap synchronization. Kubernetes pins the existing SDK rc.2.
- Authenticated mutation-rejection audit receipts and recovery of certificate
  audit events rejected by the earlier identifier-length check.
- A development-only MySQL native-AIO workaround, while retaining MySQL 8.0.22.
- Project, Go-runtime, dependency and UI license materials; covered MySQL driver
  source; aggregate SBOMs and per-file inventories in each binary bundle.

## Downloads

Choose one archive for macOS or Linux, on amd64 or arm64, and download
`SHA256SUMS` to check it before extraction. Each archive contains both commands,
deployment examples, build metadata and the distribution materials above.
The optional `review-records-2026-09-12.tar.gz` is text-only historical evidence,
not required to install or run Configra. It has a separate checksum file.

macOS executables are not Apple-signed or notarized. No public container image
is supplied; build the included Dockerfiles and publish to your own registry.

## Evaluation only

This is not a stable production release. Machine permissions cover a whole
Environment; human roles cover the whole workspace. The ten-minute 1000 QPS
gate, bounded backend inventories, key-rotation/recovery and final operational
acceptance remain open. Do not infer a production SLA from a successful build
or functional test. See [production readiness](https://github.com/viber-ops/configra/blob/v0.1.0-rc.2/docs/production-readiness.md).

Configra must not supply its own database credentials, Master Key or other
bootstrap secrets through its provider. Keep them external and separately backed up.

## Existing checkouts

Main has new history. Keep any local changes and use a fresh clone in another
directory instead of forcing a pull over a working checkout. Server rc.1 has
been withdrawn; do not retag it or reuse its old artifacts as rc.2. SDK module
versions have not been rewritten.
