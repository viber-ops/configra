# Configra v1.2.2

This patch makes inventory lists show active resources by default, explains
create failures, and restores reproducible image builds. It remains compatible
with configra-go v1.2.0. The MySQL schema stays at **4**.

列表默认只显示使用中的资源，创建失败时说明具体原因，修复镜像构建中证书源码包无法下载的问题，并更新 Go 1.26.10 与 Vite 8.3.5 安全补丁。
SDK 保持 v1.2.0；从 v1.2.1 升级不需要数据库结构迁移。

## Changes / 变更

- **Status filter on every inventory list** ([#26](https://github.com/viber-ops/configra/issues/26)).
  Environments, Configs, Vault Items and API Tokens default to **Active**;
  choose Archived (Revoked for Tokens) or All to see inactive rows. Archiving or
  revoking a row removes it from the Active view. The API already supported
  `status=active|archived|revoked|all`; only the UI default changes.
- Creating an Environment, Config or Vault Item with a key that is already in
  use now says so and shows a copyable Request ID, instead of a generic failure.
  Rename, archive and restore failures also keep the server's reason.
- Searches with no results say that nothing matches the current filters instead
  of "No managed resources yet".
- The Environments table keeps its row actions visible at common laptop widths,
  and its search and status controls use the standard toolbar style.
- Chinese UI: Archive/Confirm archive read 归档/确认归档, and the Active status
  reads 使用中.
- Docker builds fetch the reviewed `ca-certificates` source from Debian
  Snapshot; the live security archive removes superseded versions, which made
  image builds fail with HTTP 404. The Go 1.26.10 builder carries
  `20250419~deb12u2`, a Debian security update that distrusts **emSign ECC Root
  CA - G3** and **Comodo AAA Services root** (Debian #1151413). The shipped trust
  bundle is the previous 150 roots minus those two; license texts and scope are
  unchanged ([verification](../verification/2026-11-04.md)).
- `web/scripts/local-ui.mjs` screenshots match the current Administration tabs.
- CI, release packaging and Docker builders move from Go 1.26.9 to **1.26.10**
  for GO-2026-6809 (`crypto/x509`). Kubernetes source builds now require Go
  **1.26.10**; the core/CLI and SDK compatibility floor remains Go 1.25.13.
  Curated runtime notices are byte-identical ([verification](../verification/2026-11-04.md)).
- The frontend build tool Vite updates to 8.3.5 for high-severity advisories
  (build-time only; the shipped UI code is unaffected).

## Upgrade from v1.2.1 / 从 v1.2.1 升级

1. Preserve the current binary/image and configuration and take the usual
   verified backup.
2. Restart Management, API and workers with the matching v1.2.2 build. Bootstrap,
   ports, Master Key and service-account grants are unchanged.
3. No `migrate` step or new MySQL/ClickHouse DDL is required. The database
   remains schema **4**.
4. Reload the Management page. Bookmarked list URLs without `status` now show
   active rows only; add `?status=all` to keep the previous view.

从更早版本升级，仍需依次完成 [v1.1.0](v1.1.0.md) 与 [v1.2.0](v1.2.0.md) 的迁移步骤。

## Rollback / 回退

v1.2.2 changes no stored data. Rolling back to v1.2.1 binaries restores the
previous list defaults and error text; no database action is needed.
