# Configra v0.1.0-rc.1

First Viber Ops preview release: a self-hosted configuration and sensitive-value
service with an embedded management UI, Go SDK, and Kubernetes integrations.

- Versioned YAML/JSON configuration and environment-resolved Vault references.
- Redesigned light/dark management workspace and mobile navigation.
- Managed client CAs, encrypted CA signing-key retention, one-time private exports,
  client issuance and revocation.
- Kubernetes CSI file provider and namespaced native Secret/ConfigMap controller.
- SDK-owned HTTPS transport, bounded responses, Viper snapshots and polling.
- Security fixes and regression coverage documented in the review.

## Downloads

Four archives cover macOS and Linux, each on amd64 and arm64. Each includes
`configra`, `configra-kubernetes`, deployment examples and build metadata.
Check `SHA256SUMS` before extracting. macOS binaries are not Apple-signed or
notarized. No public container image is included in this release.

## Preview, not production acceptance

This tag is cut from the reviewed feature branch; it does not merge the draft
feature PR. Machine grants are Environment-wide, human roles are workspace-wide,
and this is not an untrusted multi-tenant secret store. Configra's bootstrap
Master Key and credentials must remain external.

The current 1000 QPS performance gate did not pass on the shared test host.
Gateway rejection audit coverage, bounded inventory APIs and automated Master Key
rotation remain follow-up work. Existing functional/container/cluster evidence
does not imply a production SLA or independent security certification.

Review the [security boundaries](https://viber-ops.github.io/docs/configra/security/)
and perform deployment-specific load and recovery validation before production.
