# Pin release sets within one Config and Environment stream

A Release Set pins one Config Revision, every Vault Revision it resolves, and up to 31 File members; a stream is scoped to the anchoring Config and Environment so one scoped writer cannot replace another application's active release. Preparation records an immutable metadata-only manifest from one database snapshot; activation/rollback use a monotonic generation compare-and-swap, and batch reads resolve the whole set in one snapshot with current authentication, scope and resource-availability checks. Existing current-value endpoints keep their semantics; release consumers opt in, and the manifest references retained encrypted Vault history rather than creating another plaintext or encrypted value store requiring a separate key-rotation path.
