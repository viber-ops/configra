# Use immutable Resource Keys

Environment, Config, Vault Namespace, Vault Item, and Field use immutable machine-facing Resource Keys; managed resources also have separate mutable Display Names, while a Vault Namespace is only an identity segment and has none. Field type is immutable. Keys match `[a-z][a-z0-9_-]{0,62}`, reserving `.` as the Vault Reference separator, while Display Names remain unrestricted human-facing labels. A Vault Item is uniquely identified by `(namespace_key, resource_key)`, so the same Item Key may safely exist in different Namespaces. Client contracts and Vault References depend on Keys; authorization depends only on the Environment Key. Removal is a reversible Archive rather than physical deletion, archived identities are never reused, and lifecycle changes create Audit Events without artificial content Revisions, preventing renames or historical cleanup from silently redirecting clients.
