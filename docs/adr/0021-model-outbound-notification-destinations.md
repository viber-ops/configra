# Model outbound Notification Destinations

V1 models administrator-configured outbound notifications as typed Notification Destinations: Generic Webhook and Feishu Bot. Generic Webhook sends Configra's Event envelope and may add an HMAC-SHA256 signature using a shared Secret entered by the administrator; Feishu Bot renders the event into Feishu's required message and signing format. Slack and other provider adapters are deferred until requested rather than treated as if they accepted the generic payload.

Destination URLs and optional Secrets are supplied and editable in Management, encrypted with KeyProvider, and never generated by Configra. The full URL is sensitive because provider credentials may be embedded in it; UI and records expose only a safe Host and masked suffix. Notifications include operation, Environment, Vault Namespace when applicable, Resource Keys, Revision, actor, time, and Management link but never Config content, Vault values, or Diff content.
