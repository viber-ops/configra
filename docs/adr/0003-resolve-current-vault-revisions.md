# Resolve current Vault revisions

Full-scalar Vault References have exactly four segments, `{vault.<namespace>.<item>.<field>}`, and resolve against the current Revision of that exact composite Vault Item identity. Three-segment references are invalid, and references cannot pin historical revisions. Doubled braces escape a reference into literal single-braced text. Each Resolved Config is produced from one consistent database snapshot and returns its Config Revision, every Vault Item Revision used under a `<namespace>.<item>` key, and a composite ETag derived from that version set. Activating an old value requires restoring the Item, which creates a new current Revision and audit trail; if reproducible releases later require dependency pinning, Configra will model a complete release snapshot rather than independent Field-level pins.
