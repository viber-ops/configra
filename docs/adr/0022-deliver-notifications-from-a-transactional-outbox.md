# Deliver notifications from a transactional Outbox

A successful Mutation commits its Audit Outbox Event and Notification Outbox Event in the same MySQL transaction. Management Server writes Audit Events to ClickHouse and delivers notifications asynchronously without Core NATS, providing at-least-once delivery while accepting duplicates and out-of-order arrival. Generic Webhook treats any 2xx as success; provider adapters also validate their response body. Network failures, timeouts, 429, and 5xx retry with jitter up to eight attempts and honor `Retry-After`; other 4xx become Dead immediately, and administrators may manually redeliver. Pending attempts use the Destination's latest URL and Secret.

Outbound requests default to public HTTPS on port 443, disable proxies and redirects, and validate the actual resolved address immediately before `connect`. Cold-start Configuration may explicitly allow exact internal Hosts or CIDRs (and their custom ports) and add a global CA bundle; loopback, link-local/metadata, multicast, unspecified, NAT64, and unsafe transition ranges remain blocked, and individual Destinations cannot skip TLS verification. Feishu Bot additionally accepts only the official `open.feishu.cn/open-apis/bot/v2/hook/...` URL shape. Test sends use the real provider format and record only safe status, latency, attempt, and provider error metadata; response bodies, full URLs, and Secrets are never persisted.
